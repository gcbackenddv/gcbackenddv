- **Features:** Live chat, role-based access, smart location flow, order management

Blood donation management & crowdfunding platform connecting donors with critical blood needs.
- **Tech:** React 18, Express.js, MongoDB, Firebase Auth, Stripe
- **Features:** Donation requests, status tracking, secure payments, admin dashboard

- **Features:** Protected routes, smooth animations, user dashboards
